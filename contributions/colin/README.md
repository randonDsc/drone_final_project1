# Colin — Isaac Lab drone stabilization

Checkpoint contribution on branch `colin-drone-simulator-isaac-lab`.

Start with [the project README](IsaacLab_Drone_Project/README.md), then [the checkpoint summary](IsaacLab_Drone_Project/docs/CHECKPOINT.md).

This independently runnable project adds Lee/PID baselines and repeatable validation: 18/18 calm-flight episodes passed. It is not yet integrated with the repository's other simulator. See [setup](IsaacLab_Drone_Project/docs/SETUP.md) and [code map](IsaacLab_Drone_Project/docs/CODE_MAP.md).

The project expects its IsaacLab dependency beside it in this directory. That dependency is excluded from Git. Generated data, environments and model checkpoints are not included.
